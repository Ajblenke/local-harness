# Project profiles

Create a profile when onboarding a target project.
Record its absolute directory, project owner, relevant instruction paths, acceptance checks, and model capability ordering.
Give its reviewer a dedicated criteria file and name that file in each proposal.
Update criteria as requirements change and record the criteria revision used for each review.
Keep private paths and project knowledge in local state when they are unsuitable for this repository.
The initial skeleton supplies the profile convention; automatic loading and criteria revision tracking remain future work.
