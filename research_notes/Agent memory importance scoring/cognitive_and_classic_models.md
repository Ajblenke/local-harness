# Cognitive science and classical CS/statistics models for scoring lesson memory importance, decay, and retention

Scope note: the target system is a set of one-line lesson bullets with (helpful, harmful) counts (usually 0-4), `added` date, `last_seen` date, and optionally a use history.
Current rule: `weight = (1 + helpful - harmful) * 0.5^(days_since_seen / 60)`; 14-day probation shows new bullets; a 6000-char budget picks what fits; archive at stale 180 d and weight < 0.25, or harmful >= 3 and harmful > helpful.

Worked numbers marked "computed" were calculated by me in Python from the stated formulas.

## Q1. ACT-R base-level activation, rational analysis, spreading activation, threshold and noise

### Takeaway
ACT-R scores a memory by log odds of being needed: B = ln(sum_j t_j^-d) with d = 0.5, plus a context term sum_j W_j S_ji, plus noise, and retrieval succeeds with logistic probability around a threshold tau.
It is the most principled drop-in replacement for the user's single last-seen exponential, because it uses the full use history (frequency and recency together) and decays as a power law, which Anderson and Schooler showed matches how often information is actually needed again in real environments.

### Cited Findings
- Base-level learning: B_i(t) = ln( sum_{k=1..n} t_k^-d ) (+ optional constant beta), where t_k is the time since the k-th use and d is the decay rate; the full activation is A_i = B_i + sum_j w_j s_ij, where w_j in [0,1] is the salience of context element j and s_ij the association strength - [Whitehill, Understanding ACT-R - an Outsider's Perspective, arXiv:1306.0125](https://arxiv.org/abs/1306.0125) [fetched]
- Association strength s_ij is a log likelihood ratio, approximated as s_ij ~= log( p(N_i | C_j) / p(N_i) ), i.e. how much more likely chunk i is needed when cue j is in context, estimated from usage history - [arXiv:1306.0125](https://arxiv.org/abs/1306.0125) [fetched]. The standard ACT-R implementation instead uses the fan approximation S_ji = S - ln(fan_j), with S the maximum associative strength (:mas) and W_j = W / (number of sources), default W = 1 - [ACT-R 7 reference manual](http://act-r.psy.cmu.edu/actr7.x/reference-manual.pdf) [canonical, not fetched: server returned 503]
- Retrieval probability is logistic in activation: P(recall) = 1 / (1 + e^{-(A - tau)/s}), with tau the retrieval threshold and s the noise scale - [arXiv:1306.0125](https://arxiv.org/abs/1306.0125) [fetched]. Retrieval latency is T = F e^{-A} - [ACT-R reference manual](http://act-r.psy.cmu.edu/actr7.x/reference-manual.pdf) [canonical, not fetched]
- Typical parameters: d = 0.5 is the conventional ACT-R decay (:bll 0.5); :rt (tau) default 0; activation noise :ans commonly 0.2-0.5 (logistic noise, variance pi^2 s^2 / 3) - [ACT-R reference manual](http://act-r.psy.cmu.edu/actr7.x/reference-manual.pdf) [canonical, not fetched]
- The decay rate is not constant across the literature: Pavlik and Anderson make each trace's decay depend on activation at the time of that use, d_k = c e^{m_{k-1}} + alpha (c ~ 0.2 to 0.3, alpha ~ 0.18 in their fits), which produces the spacing effect because massed uses (high existing activation) decay faster - [arXiv:1306.0125](https://arxiv.org/abs/1306.0125) (summary of the definitions) [fetched]; [Pavlik & Anderson 2005, Cognitive Science 29:559](https://doi.org/10.1207/s15516709cog0000_14) [canonical, not fetched for the constants]
- Optimized learning (Anderson & Lebiere 1998) avoids storing every timestamp: B ~= ln( n / (1 - d) ) - d ln(L), where n is the number of uses and L the lifetime since creation; Petrov (2006) notes this approximation "does not capture the transient boost after each use" and proposes a hybrid that keeps the k most recent timestamps exactly and approximates the rest; ACT-R's `:ol` parameter set to an integer does exactly this hybrid - [Petrov 2006, ICCM, alexpetrov.com/pub/iccm06](https://alexpetrov.com/pub/iccm06); [ACT-R users list, Bothell 2006](https://mailman.srv.cs.cmu.edu/pipermail/act-r-users/2006-February/001103.html) [fetched via search snippets; the exact OL formula text itself was not displayed, so it is canonical, not fetched]
- Petrov's hybrid (as usually written): B ~= ln( sum_{j=1..k} t_j^-d + (n - k)(L^{1-d} - t_k^{1-d}) / ((1 - d)(L - t_k)) ) - [Petrov 2006](https://alexpetrov.com/pub/iccm06) [canonical, not fetched: page 503]
- Anderson and Schooler (1991) analysed New York Times headlines, parental speech, and email, finding that the probability an item is needed shows the same frequency, recency, and spacing relationships as human memory, and argued memory is adapted to these environmental statistics (need odds decline as a power function of time since last occurrence, and rise as a power function of frequency) - [Anderson & Schooler 1991, Psychological Science 2:396-408](https://doi.org/10.1111/j.1467-9280.1991.tb00174.x) (abstract via [Bibsonomy](https://www.bibsonomy.org/bibtex/205f72a898d20edc63002bb94285d799), [CMU KiltHub](https://kilthub.cmu.edu/articles/journal_contribution/Does_Memory_Reflect_Statistical_Regularity_in_the_Environment_/6614462)) [abstract fetched; the power-law exponents were not in the retrieved text]
- ACT-R's production utility p is estimated by updating a Beta distribution on success/failure, i.e. ACT-R itself already pairs power-law activation with Beta-Binomial success counting - [arXiv:1306.0125](https://arxiv.org/abs/1306.0125) [fetched]

### Inferences
- Computed (d = 0.5, times in days): one use 60 days ago gives B = -2.05; one use 180 days ago gives B = -2.60; uses at 1, 30, 60 days ago give B = +0.27; uses at 5, 10, 20, 40, 80 days give B = +0.23. So the power law separates "seen once, long ago" from "seen repeatedly" far more than the current formula, which only looks at the last-seen date and ignores how many times a bullet was used.
- Power-law decay is much gentler in the tail than the current 60-day half-life exponential: 0.5^(180/60) = 0.125, while t^-0.5 drops only by a factor of sqrt(3) = 1.73 between 60 and 180 days. Under ACT-R, a long-unused but once-heavily-used lesson stays retrievable, which matches the intuition that rare-but-critical lessons (a deploy gotcha) should not be archived just for being idle.
- Mapping onto a bullet: store a capped list of the last k "seen/used" timestamps plus a total count n (Petrov hybrid with k = 3 to 5), compute B; add a usefulness term from helpful/harmful (see Q3) as a separate additive log-odds term, e.g. A = B + ln(posterior odds helpful) + spreading term; show bullets with A above a threshold or rank by A within the budget.
- Spreading activation is the principled slot for context relevance: S_ji from tag or keyword co-occurrence with the current task (fan = number of bullets sharing a tag, so generic tags contribute little). This is a speculative but natural mapping; ACT-R itself does not define what "context" is precisely, as Whitehill notes.
- Noise plus threshold gives a natural stochastic exploration: adding logistic noise with s ~ 0.25 to A before ranking yields occasional surfacing of low-activation bullets, akin to Thompson sampling (Q4).

## Q2. Forgetting curves, spacing, and spaced repetition algorithms (Ebbinghaus, power vs exponential, Pimsleur, Leitner, SM-2, HLR, FSRS, MEMORIZE)

### Takeaway
The literature favours power-law (or mixture-of-exponentials) forgetting over a single exponential, and the modern best practice (FSRS) uses a power-law retrievability R(t,S) with a per-item stability S that grows after each successful use and shrinks after a failure.
For the lesson memory, "helpful" maps to a successful review that multiplies stability, "harmful" to a lapse that shrinks it, and HLR's Leitner special case h = 2^(helpful - harmful) is an almost literal drop-in.

### Cited Findings
- Ebbinghaus exponential as used by Duolingo HLR: p = 2^(-Delta/h), where Delta is lag since last practice and h is the half-life - [Settles & Meeder 2016, ACL, P16-1174](https://aclanthology.org/P16-1174.pdf) [fetched]
- HLR half-life model: h_hat = 2^(Theta . x), with x a feature vector (counts of past correct x_plus, incorrect x_minus, total, bias, plus optional lexeme indicator features); square root of the counts worked better than raw counts - [Settles & Meeder 2016](https://aclanthology.org/P16-1174.pdf) [fetched]
- HLR loss: l = (p - p_hat)^2 + alpha (h - h_hat)^2 + lambda ||Theta||^2, with lambda = 0.1, alpha = 0.01, learning rate eta = 0.001; predictions bounded p in [0.0001, 0.9999], h in [15 min, 9 months] - [Settles & Meeder 2016](https://aclanthology.org/P16-1174.pdf) [fetched]
- Pimsleur and Leitner are special cases of HLR: Pimsleur's schedule (5 s, 25 s, 2 min, 10 min, 1 h, 5 h, 1 d, 5 d, 25 d, 4 mo, 2 y) is reproduced by Theta = {x_n: 2.4, x_b: -16.5} (r^2 = 0.999); Leitner corresponds to Theta = {x_plus: 1, x_minus: -1}, i.e. each correct doubles the interval and each incorrect halves it - [Settles & Meeder 2016, appendix](https://aclanthology.org/P16-1174.pdf) [fetched]
- HLR results: MAE 0.128 vs Leitner 0.235 and Pimsleur 0.445 (constant baseline 0.175); Leitner had slightly higher AUC (0.542 vs 0.538); dropping the h term from the loss more than doubles MAE (0.350); in an operational test HLR improved daily student engagement by 12% - [Settles & Meeder 2016](https://aclanthology.org/P16-1174.pdf) [fetched]
- MEMORIZE: recall probability m(t) = exp(-n(t)(t - t_r)), with forgetting rate n updated multiplicatively on each review: n <- (1 - alpha) n on success, n <- (1 + beta) n on failure; loss = (1 - m(t))^2 + q u(t)^2; the optimal review intensity is u(t) = q^{-1/2} (1 - m(t)), i.e. review rate proportional to the probability of having forgotten - [Tabibian et al. 2019, arXiv:1712.01856 (PNAS)](https://arxiv.org/abs/1712.01856) [fetched]
- MEMORIZE evaluation on Duolingo data used q = 3 x 10^-4 and compared to uniform and threshold baselines; it "tends to space the reviews more than the threshold based schedule, achieving the same recall pattern with less effort" - [arXiv:1712.01856](https://arxiv.org/abs/1712.01856) [fetched]
- FSRS-6 forgetting curve (current version): R(t,S) = (1 + factor * t/S)^(-w20), factor = 0.9^(-1/w20) - 1, so R(S,S) = 0.9 by construction; w20 (decay) is trainable, default 0.1542 - [open-spaced-repetition awesome-fsrs wiki, The Algorithm](https://github.com/open-spaced-repetition/awesome-fsrs/wiki/The-Algorithm) [fetched]
- FSRS-4.5 / FSRS-5 curve: R(t,S) = (1 + (19/81) t/S)^(-0.5), fixed decay -0.5; with w20 = 0.5 the FSRS-6 factor reduces to 19/81 - [awesome-fsrs wiki](https://github.com/open-spaced-repetition/awesome-fsrs/wiki/The-Algorithm) [fetched]
- FSRS-5 difficulty: D0(G) = w4 - e^{w5 (G - 1)} + 1; Delta D = -w6 (G - 3); linear damping D' = D + Delta D * (10 - D)/9; mean reversion D'' = w7 D0(4) + (1 - w7) D' (G is grade 1 Again, 2 Hard, 3 Good, 4 Easy) - [awesome-fsrs wiki](https://github.com/open-spaced-repetition/awesome-fsrs/wiki/The-Algorithm) [fetched]
- FSRS-6 same-day stability: S' = S * e^{w17 (G - 3 + w18)} * S^{-w19} - [awesome-fsrs wiki](https://github.com/open-spaced-repetition/awesome-fsrs/wiki/The-Algorithm) [fetched]
- FSRS-6 default parameters: w0 0.212, w1 1.2931, w2 2.3065, w3 8.2956 (initial stability in days for grades 1-4), w4 6.4133, w5 0.8334, w6 3.0194, w7 0.001, w8 1.8722, w9 0.1666, w10 0.796, w11 1.4835, w12 0.0614, w13 0.2629, w14 1.6483, w15 0.6014, w16 1.8729, w17 0.5425, w18 0.0912, w19 0.0658, w20 0.1542 - [awesome-fsrs wiki](https://github.com/open-spaced-repetition/awesome-fsrs/wiki/The-Algorithm) [fetched]
- FSRS stability after successful recall (the standard FSRS-4.5+ form; the wiki page I fetched did not restate it for FSRS-6): S'_r = S * (1 + e^{w8} (11 - D) S^{-w9} (e^{w10 (1 - R)} - 1) * hardPenalty(w15 if G=2) * easyBonus(w16 if G=4)); stability after lapse: S'_f = w11 * D^{-w12} * ((S + 1)^{w13} - 1) * e^{w14 (1 - R)}; initial stability S0(G) = w_{G-1} - [FSRS algorithm wiki](https://github.com/open-spaced-repetition/awesome-fsrs/wiki/The-Algorithm); [fsrs4anki](https://github.com/open-spaced-repetition/fsrs4anki) [canonical, not fetched verbatim this session; index mapping to w8-w16 matches the defaults table above but should be verified]
- Key structural FSRS ideas: stability increase is larger when R was low at review time (spacing effect: "desirable difficulty"), smaller when S is already large (saturation, S^-w9), and smaller for harder items (11 - D) - same sources [canonical]
- SM-2 (SuperMemo 1987): EF' = EF + (0.1 - (5 - q)(0.08 + (5 - q) 0.02)), EF floored at 1.3, initial 2.5; intervals I1 = 1, I2 = 6, In = I_{n-1} * EF; grade q < 3 resets repetitions - [SuperMemo, Algorithm SM-2](https://super-memory.com/english/ol/sm2.htm) [canonical, not fetched]
- Power vs exponential forgetting: Wixted and Ebbesen (1991) found power functions fit retention data better than exponentials; Rubin and Wenzel (1996) fitted 105 two-parameter functions to 210 retention data sets and found the logarithmic, power, exponential-in-square-root, and hyperbola-in-square-root forms fit best, with simple exponentials doing poorly; a mixture of exponentials with different rates (e.g. different items or traces) aggregates to a power law - [Wixted & Ebbesen 1991, Psych Science](https://doi.org/10.1111/j.1467-9280.1991.tb00175.x); [Rubin & Wenzel 1996, Psych Review 103:734](https://doi.org/10.1037/0033-295X.103.4.734) [canonical, not fetched]
- Spacing effect: Cepeda et al. (2006) meta-analysis of 317 experiments confirms distributed practice beats massed, with optimal gap growing with retention interval - [Cepeda et al. 2006, Psych Bulletin 132:354](https://doi.org/10.1037/0033-2909.132.3.354) [canonical, not fetched]

### Inferences
- Computed comparison at S = 60 d (or half-life 60 d): at 14 days, FSRS-6 R = 0.969, FSRS-4.5 R = 0.974, user's exponential = 0.851; at 60 days 0.900 / 0.900 / 0.500; at 180 days 0.809 / 0.766 / 0.125. The current 60-day half-life is aggressive in the tail; the archive rule (weight < 0.25 at 180 days) is effectively archiving anything with net score 1 at 120+ days.
- Near-literal mapping (Leitner/HLR): half_life = h0 * 2^(helpful - harmful) (or with sqrt counts), recall = 2^(-days_since_seen / half_life). This keeps the user's exponential form but makes helpful votes extend memory life instead of scaling height, which is the HLR insight; h0 = 60 days reproduces the current decay for net-zero bullets.
- FSRS-style mapping: treat each "helpful" as grade Good (S grows by an SInc factor that is larger when R was low), each "harmful" as Again (S shrinks via S'_f), "seen but neither" as no review (no update), and D as a per-bullet difficulty initialized neutral. Retrievability R(t,S) then plays the role of the decay multiplier. With counts of 0-4 the 21 FSRS weights cannot be fitted per user; default weights would be borrowed from flashcard data whose semantics differ, so this is speculative.
- MEMORIZE gives the one directly actionable scheduling rule: surface an item with intensity proportional to (1 - m(t)), i.e. when it is about to be forgotten. For an agent prompt the analogue is "refresh" exposure of high-value bullets whose recall would otherwise lapse; but in the agent setting "forgetting" is literal (not shown = not in context), so the review-scheduling motivation transfers only loosely.
- Important semantic mismatch: in spaced repetition, a review is a test whose outcome is observed; in the lesson memory, "seen" (shown in prompt) and "helped" are different events. Updating stability on mere exposure without an outcome would be inconsistent with all of these models.

## Q3. Statistical scoring of small-count helpful/harmful votes

### Takeaway
With 0-4 votes, the raw difference (1 + helpful - harmful) is high variance and can go negative; a Beta-Binomial posterior (Laplace smoothing is the Beta(1,1) special case) gives a bounded, shrunk estimate, and the Wilson lower bound gives a conservative one suited to the archive decision.
Time-decayed counts (exponentially weighted votes) or HN-style gravity let old votes count less, which addresses non-stationary usefulness.

### Cited Findings
- Wilson score lower bound (Evan Miller, "How Not To Sort By Average Rating"): LB = ( p_hat + z^2/(2n) - z sqrt( (p_hat(1 - p_hat) + z^2/(4n)) / n ) ) / (1 + z^2/n), with p_hat = positive/n, z = 1.96 for 95% confidence, and score 0 when n = 0 - [Evan Miller](https://www.evanmiller.org/how-not-to-sort-by-average-rating.html) [fetched]
- Beta-Binomial posterior mean with prior Beta(a, b): E[p] = (helpful + a) / (helpful + harmful + a + b); Laplace's rule of succession is a = b = 1 - standard result; Evan Miller's companion article "Bayesian Average Ratings" recommends a Dirichlet/Beta prior and ranking by a posterior quantile - [Evan Miller, Bayesian Average Ratings](https://www.evanmiller.org/bayesian-average-ratings.html) [canonical, not fetched]
- IMDb Top 250 Bayesian average: WR = (v/(v+m)) R + (m/(v+m)) C, with v votes, R item mean, m minimum votes (prior weight), C global mean - [IMDb help, Top 250 ratings](https://help.imdb.com/article/imdb/track-movies-tv/ratings-faq/G67Y87TFYYP6TWAV) [canonical, not fetched]
- Reddit "best" comment sort uses the Wilson lower bound (adopted 2009 citing Evan Miller) - [Randall Munroe, Reddit blog 2009 "reddit's new comment sorting system"](https://redditblog.com/2009/10/15/reddits-new-comment-sorting-system/) [canonical, not fetched]
- Hacker News gravity: score = (P - 1) / (T + 2)^G with G = 1.8, T in hours; actual news.arc raises (votes - 1) to 0.8 and multiplies by penalty factors (e.g. 0.4 for no URL) - [Righto 2009, Inside the news.yc ranking formula](https://www.righto.com/2009/06/how-does-newsyc-ranking-work.html); [Righto 2013, How Hacker News ranking really works](https://www.righto.com/2013/11/how-hacker-news-ranking-really-works.html); [Salihefendic 2015](https://medium.com/hacking-and-gonzo/how-hacker-news-ranking-algorithm-works-1d9b0cf2c08d) [fetched via search snippets]. Caveat: Righto notes production differs from published code and formulas changed over time.
- Exponentially weighted counts (the D-UCB estimator form): N_t(gamma) = sum_s gamma^{t-s} 1{event at s}, mean = sum gamma^{t-s} X_s / N_t(gamma) - [Garivier & Moulines 2008, arXiv:0805.3415](https://arxiv.org/abs/0805.3415) [fetched]

### Inferences
- Computed comparison (helpful, harmful) -> Wilson LB (z 1.96) / Beta(1,1) mean / user's (1 + h - b): (0,0) 0.000 / 0.500 / 1; (1,0) 0.207 / 0.667 / 2; (2,0) 0.342 / 0.750 / 3; (4,0) 0.510 / 0.833 / 5; (3,1) 0.301 / 0.667 / 3; (2,2) 0.150 / 0.500 / 1; (1,3) 0.046 / 0.333 / -1; (0,3) 0.000 / 0.200 / -2.
- The current formula goes negative at harmful >= helpful + 2, so a negative weight times decay increases toward zero over time, meaning a harmful bullet's weight rises as it ages; this is a latent bug the Beta mean avoids (always in (0,1)).
- Wilson LB at z = 1.96 is very conservative at n <= 4 (a 4-for-4 bullet scores only 0.51, and every unvoted bullet scores 0); it fits the archive decision ("are we confident it's bad?" use the Wilson upper bound of harm, or LB of help) better than ranking. A lower z (e.g. 1.0, about 68%) is a common softening; that choice is a judgement call, not sourced.
- Recommended prior for the Beta mean: Beta(a, b) with a/(a+b) set to the observed global helpful rate across all bullets and a + b ~ 2 to 4 (IMDb-style m), so a brand-new bullet scores the population average rather than 0.5. Harmful votes could be weighted more than helpful (asymmetric cost) by counting each as k > 1 failures; speculative.
- Time-decayed votes: keep helpful_eff = sum gamma^{days since vote} over votes (or update incrementally: h_eff <- h_eff * gamma^{dt} + 1); with gamma = 0.5^(1/180) a vote has half weight after 180 days. Plug h_eff, b_eff into the Beta mean. This requires vote timestamps or an incremental update at each vote.

## Q4. Exploration vs exploitation (Thompson sampling, UCB1, non-stationary bandits, probation as optimism)

### Takeaway
Choosing which bullets to show under a char budget is a combinatorial bandit with uncertain, drifting rewards; Thompson sampling from each bullet's Beta(helpful + a, harmful + b) is the simplest principled replacement for the fixed 14-day probation, and discounted or sliding-window variants handle usefulness that changes as the codebase changes.

### Cited Findings
- UCB1: choose argmax_i X_bar_i + c_t(i), with padding c_t(i) = B sqrt(xi log t / N_t(i)) (classic UCB1 uses sqrt(2 ln t / n_i)) - [Garivier & Moulines 2008, arXiv:0805.3415](https://arxiv.org/abs/0805.3415) [fetched]; [Auer, Cesa-Bianchi & Fischer 2002, Machine Learning 47:235](https://doi.org/10.1023/A:1013689704352) [canonical, not fetched]
- Discounted UCB: X_bar_t(gamma, i) = (1/N_t(gamma, i)) sum_s gamma^{t-s} X_s 1{I_s = i}, N_t(gamma, i) = sum_s gamma^{t-s} 1{I_s = i}, padding c_t(gamma, i) = 2B sqrt(xi log n_t(gamma) / N_t(gamma, i)), n_t(gamma) = sum_i N_t(gamma, i); gamma = 1 recovers UCB1 - [arXiv:0805.3415](https://arxiv.org/abs/0805.3415) [fetched]
- Sliding-window UCB: same, using only the last tau plays, padding B sqrt(xi log(min(t, tau)) / N_t(tau, i)); both D-UCB and SW-UCB match the lower bound for abruptly changing environments up to a log factor - [arXiv:0805.3415](https://arxiv.org/abs/0805.3415) [fetched]
- Thompson sampling with Beta priors: sample theta_i ~ Beta(S_i + a, F_i + b), pick the arm with the largest sample, update counts on outcome - [Russo et al., A Tutorial on Thompson Sampling, arXiv:1707.02038](https://arxiv.org/abs/1707.02038); [Chapelle & Li 2011, NeurIPS, "An Empirical Evaluation of Thompson Sampling"](https://papers.nips.cc/paper/4321-an-empirical-evaluation-of-thompson-sampling) [canonical, not fetched]
- Optimistic initialization (setting initial value estimates high to force early trials) is a standard exploration device - [Sutton & Barto, Reinforcement Learning: An Introduction, 2nd ed., sec 2.6](http://incompleteideas.net/book/the-book-2nd.html) [canonical, not fetched]

### Inferences
- The 14-day probation is a hard form of optimistic initialization: every new bullet gets "infinite" score for a fixed time regardless of evidence. UCB gives the soft version: the bonus sqrt(2 ln t / n_i) is large when a bullet has few observed outcomes and shrinks as evidence accumulates, with no arbitrary clock. Thompson sampling gives the same effect stochastically: a Beta(1,1) bullet has wide posterior and frequently samples high.
- Concrete rule: at each prompt build, draw theta_i ~ Beta(h_eff + a, b_eff + b) per bullet, multiply by a recency/retrievability factor (Q1/Q2) and a context relevance factor, then fill the char budget by theta per char (Q5). This replaces probation, keeps exploring underexposed bullets, and still exploits proven ones. Determinism, if needed, can come from seeding by date.
- Credit assignment caveat: the bandit framing assumes the helpful/harmful outcome is attributable to a shown bullet; if votes come from an LLM judging relevance afterward, outcomes are noisy and correlated across bullets shown together (a combinatorial semi-bandit). Not addressed by any source found.
- Non-stationarity: lessons go stale as code and tools change; D-UCB with gamma per day of about 0.99 to 0.996 (effective memory 100 to 250 days) is a reasonable starting range; that range is my judgement, not sourced.

## Q5. Cache replacement analogues (LRU, LFU, LRFU, ARC, 2Q, GreedyDual-Size) and knapsack framing

### Takeaway
The prompt budget is a cache with variable-size entries, so GreedyDual-Size (value per byte with aging) and LRFU (a single exponentially decayed recency-frequency score) are the closest analogues; the per-prompt selection itself is a 0/1 knapsack whose greedy value/size solution is near optimal when items are small relative to the budget.

### Cited Findings
- LRFU (Lee et al. 2001): each block's CRF = sum over past references of F(t_now - t_ref), with F(x) = (1/2)^{lambda x}; lambda = 0 is LFU, lambda = 1 approaches LRU; computable incrementally as C_new = F(0) + F(dt) C_old - [Lee et al. 2001, IEEE Trans. Computers 50(12):1352](https://doi.org/10.1109/TC.2001.970573) [canonical, not fetched]
- ARC (Megiddo & Modha 2003): two LRU lists, T1 (seen once recently) and T2 (seen at least twice), plus ghost lists B1, B2 of evicted keys; target size p adapts, increasing on hits in B1 and decreasing on hits in B2, balancing recency and frequency without tuning - [Megiddo & Modha, FAST 2003, "ARC: A Self-Tuning, Low Overhead Replacement Cache"](https://www.usenix.org/conference/fast-03/arc-self-tuning-low-overhead-replacement-cache) [canonical, not fetched]
- 2Q (Johnson & Shasha 1994): new items enter a FIFO probation queue A1in; only items re-referenced while remembered in the ghost queue A1out are promoted to the main LRU Am, suggested sizes Kin ~ 25% and Kout ~ 50% of cache - [Johnson & Shasha, VLDB 1994](https://www.vldb.org/conf/1994/P439.PDF) [canonical, not fetched]
- GreedyDual-Size (Cao & Irani 1997, extending Young's GreedyDual): H(p) = L + cost(p)/size(p); evict min H, set L to the evicted H; on hit, reset H(p) = L + cost/size. GDSF (Cherkasova 1998) adds frequency: H = L + freq * cost / size - [Cao & Irani, USITS 1997, "Cost-Aware WWW Proxy Caching Algorithms"](https://www.usenix.org/conference/usits-97/cost-aware-www-proxy-caching-algorithms) [canonical, not fetched]
- 0/1 knapsack: maximize sum v_i x_i subject to sum w_i x_i <= W; greedy by v_i/w_i plus best single item is a 1/2 approximation, and exact DP is O(nW) - [standard result; e.g. Kellerer, Pferschy & Pisinger, Knapsack Problems, Springer 2004](https://doi.org/10.1007/978-3-540-24777-7) [canonical, not fetched]

### Inferences
- The user's current scheme is closest to LRU with a weight multiplier; it ignores bullet length. Under a char budget, ranking by score / chars (GreedyDual-Size logic) is strictly better at packing value, and it penalizes verbose bullets, which is a desirable incentive.
- LRFU is mathematically the same as a decayed hit count; with lambda = 1/60 per day it reproduces a 60-day half-life but sums all uses (frequency) rather than only the last one. It is a lighter alternative to ACT-R's power law, with the same frequency benefit.
- 2Q and ARC formalize "probation": new bullets sit in a short probationary list and are promoted to the protected list only after a second hit (a helpful vote or a second relevant retrieval). ARC's adaptive p could set how much of the 6000-char budget goes to new versus proven bullets, instead of showing all new bullets for 14 days.
- GreedyDual's aging constant L is a neat archive rule: track the inflation value L; a bullet whose H has not been refreshed and falls below L is the eviction candidate, which avoids hand-picked thresholds like 180 days.
- With roughly 50 to 150 one-line bullets and W = 6000 chars, exact DP is cheap (n x 6000 cells), so greedy is not even necessary; but greedy is simpler and near optimal since each bullet is small relative to W.

### Gaps
- None of the caching papers were fetched this session; formulas are canonical textbook versions.
- No source compares cache policies for LLM context selection.

## Q6. Neuroscience-inspired ideas (consolidation, synaptic tagging, dopamine RPE gating, replay prioritization, prioritized experience replay)

### Takeaway
Prioritized experience replay is the only one of these with exact equations directly usable (priority from surprise, sampling exponent alpha, importance weights beta); the neuroscience ideas mostly justify design choices (boost memories tied to surprising outcomes, consolidate after evidence, replay what has highest expected future value) rather than providing formulas.

### Cited Findings
- Prioritized experience replay (Schaul et al. 2015/2016): sampling probability P(i) = p_i^alpha / sum_k p_k^alpha; proportional variant p_i = |delta_i| + epsilon (delta = TD error); rank variant p_i = 1/rank(i); importance-sampling weights w_i = (N * P(i))^{-beta} / max_j w_j, with beta annealed linearly to 1 - [Schaul et al., arXiv:1511.05952](https://arxiv.org/abs/1511.05952) [fetched]
- PER hyperparameters: alpha = 0.7, beta0 = 0.5 (rank-based); alpha = 0.6, beta0 = 0.4 (proportional); new transitions are inserted with maximal priority so each is replayed at least once; DQN with PER beat uniform replay on 41 of 49 Atari games and raised Double DQN median normalized score from 111% to 128% - [arXiv:1511.05952](https://arxiv.org/abs/1511.05952) [fetched]
- Dopamine neurons encode reward prediction error (positive when outcome better than expected) - [Schultz, Dayan & Montague 1997, Science 275:1593](https://doi.org/10.1126/science.275.5306.1593) [canonical, not fetched]
- Synaptic tagging and capture: a weak potentiation sets a local "tag" that is converted to long-lasting change only if plasticity-related proteins arrive within a window (about 1 to 2 hours in the original slice work), often triggered by a strong or novel/rewarding event - [Frey & Morris 1997, Nature 385:533](https://doi.org/10.1038/385533a0) [canonical, not fetched]
- Hippocampal-VTA loop: novelty triggers dopamine release that enhances hippocampal long-term memory formation - [Lisman & Grace 2005, Neuron 46:703](https://doi.org/10.1016/j.neuron.2005.05.002) [canonical, not fetched]
- Replay prioritization: Mattar and Daw model replay as choosing memories by expected value of backup = gain x need, where need is expected future occupancy (successor representation) and gain is policy improvement from that update; this predicts forward and reverse replay patterns - [Mattar & Daw 2018, Nature Neuroscience 21:1609](https://doi.org/10.1038/s41593-018-0232-z) [canonical, not fetched]
- Systems consolidation: memories initially hippocampus-dependent are gradually reorganized into neocortex over time; complementary learning systems theory explains why a fast store plus slow interleaved consolidation avoids catastrophic interference - [McClelland, McNaughton & O'Reilly 1995, Psych Review 102:419](https://doi.org/10.1037/0033-295X.102.3.419) [canonical, not fetched]

### Inferences
- PER maps cleanly: priority p_i = |observed outcome - predicted usefulness| + epsilon, i.e. bullets whose last vote was surprising (a "proven" bullet that just hurt, or a new bullet that helped) get extra exposure to resolve uncertainty; max-priority insertion of new items is the PER version of probation, with priority decaying as soon as an outcome is observed. Sampling with alpha ~ 0.6 gives soft rather than greedy selection.
- Mattar and Daw's gain x need is a principled decomposition for the user's weight: need = ACT-R style probability the lesson's context recurs (recency, frequency, context match), gain = how much showing it changes behaviour (helpful posterior minus a baseline). Speculative mapping, but it argues for multiplying a need term by a usefulness term, which the current formula already roughly does.
- Synaptic tagging suggests a two-stage lifecycle: a new bullet is "tagged" (probationary) and is consolidated (made durable, slower decay) only if a strong signal, a helpful vote, arrives within a window; untagged bullets that never get a signal decay out. This is the same structure as 2Q, and is speculative as an engineering justification.
- Systems consolidation suggests periodically merging repeatedly helpful bullets into a slower, compressed store (e.g. promote to a stable rules file, as `CLAUDE.md` style instructions) with near-zero decay, while the fast store keeps aggressive decay. Speculative.

### Gaps
- Neuroscience sources were not fetched this session; claims are from the canonical papers' well-known findings, and the time windows are approximate.
- No quantitative model of synaptic tagging or systems consolidation exists in a form that maps directly to a scoring equation; these ideas are inspiration, not evidence for specific parameters.
