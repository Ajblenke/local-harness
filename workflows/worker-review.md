# Worker and project reviewer

Use this initial pattern for one implementation assignment with independent project review.

1. The chief of staff gathers the objective, target directory, acceptance criteria, and project review criteria.
2. It proposes one worker and one project specific reviewer, with a stronger model assigned to review.
3. Joseph confirms the pattern and model assignments before execution.
4. The worker implements the assignment in a fresh session and returns the diff and verification evidence.
5. The reviewer checks that evidence and the diff against the project's current criteria and returns actionable findings or acceptance.
6. The worker addresses findings and the reviewer checks the revisions until accepted or blocked.
7. The chief of staff reports the reviewed outcome and any remaining decisions.

For interruption, inspect the saved proposal, target repository diff, and Herdr agent state before deciding whether to resume or restart an assignment.
For a blocked agent, inspect its output and bring approval requests to Joseph.
If scope or model assignments must change, present the revised proposal for confirmation before proceeding.
Completion requires reviewer acceptance with evidence for the objective's acceptance criteria.
